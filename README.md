# GraphQL Full-Stack Library App

A modern full-stack web application built using React, Apollo Client, Node.js, Express, GraphQL, and MongoDB.

## Features
- View list of books and authors
- Add new books linked to authors
- View detailed book and author relationships
- GraphQL API with MongoDB database
- React frontend with Apollo Client

## Tech Stack
Frontend: React, Apollo Client  
Backend: Node.js, Express, GraphQL  
Database: MongoDB  

## How to Run

### Backend
cd server  
npm install  
npm start  

GraphQL Playground: http://localhost:4000/graphql

### Frontend
cd client  
npm install  
npm start  

App runs at: http://localhost:3000
